# app_calendario

Agenda personal en la nube con Firebase (Auth con Google + Realtime Database).
Materias, horario semanal y eventos mensuales, con tema claro/oscuro y color personalizable.

## Uso

```
python -m http.server 8000
```

Abrir `http://localhost:8000` e iniciar sesión con Google.

## Ramas

- `main` — versión publicada (GitHub Pages).
- `develop` — desarrollo de features.
